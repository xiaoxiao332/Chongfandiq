# 《留灯地球》M1 试玩说明

入口：Unity 菜单 **Tools → LastLight → M1 → Open Prototype**，点击 Play。场景为 `Assets/LastLight/Scenes/M1Prototype.unity`。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 / 冲刺 | WASD / Shift |
| 与附近物件交互 | E |
| 维修锤近战 | 鼠标左键，朝鼠标方向挥击 |
| 吃随身口粮 | F |
| 背包与仓储 | Tab |
| 日志与当前目标 | J |
| 建造模式 | B |
| 关闭当前界面 / 暂停 | Esc |
| 建筑旋转 | 建造模式下 R |
| 建造镜头 | 方向键平移、滚轮缩放 |

点击 Game 窗口后操作。建造时右侧选择建筑，左键放置；拆除和移动有单独按钮。建筑必须使用公共仓储里的材料，随身材料先存入仓储。建造预览说明阻挡和缺料原因。

## 可以完成什么

1. 沿暖灯找到终端，阅读苏醒信息。
2. 在家园安全拾荒带收集石料与废金属，存入公共仓储，修复应急暖炉。木材可以在应急手工台转成燃料。
3. 建造带门的小屋：至少四格地板，墙、门围合后自动出现屋顶；室内放床和仓储。床、工作台等设施需要留下通道。
4. 前往旧工坊，沿外围绕开枝角兽，阅读撤离记录并取回梁的启动件。关键件不占背包，倒下也不会失去。取件后回程捷径向所有路线开放。
5. 启动梁，领取四份维修零件，在终端回应岑的“借你一盏灯”。援助、交换与拒绝都有不同成本和可见后果，全部可以继续。
6. 建木障或加固门闩，在终端读完防御说明后确认准备。第一次袭击会等你确认，阅读和规划时世界暂停。
7. 处理受损建筑与承诺，再到终端查看后果。可以继续整理家园，或重新开始一轮。

## 损失后怎样恢复

- 安全拾荒点会补充木材、石料、纤维、口粮和废金属；徒手即可获取。
- 固定应急仓储、手工台、暖炉与维护舱不会被拆除。普通工作台坏了，仍可手工加工零件。
- 倒下由维护拖车送回家，损失每类随身普通资源的 20%（向下取整）；关键件与家园仓储保留。
- 防御失败只结算一次有限的普通物资损失，设备可以修复。墙、门和路障归零会形成缺口，修好后恢复阻挡。
- 梁的岗位是建筑修复，从公共仓储取材。缺料、停机或通路受阻时会说明原因；主角靠近损坏建筑按 E 也能维修。
- 交换承诺要求一张未分配给主角的完好访客床和两份口粮。可以延期一次，或明确撤回，不会封死主线。

## 试玩反馈

本阶段目标为 30–45 分钟核心循环，实际时长与易懂程度需要试玩记录。请留意：下一目标是否清楚、建设是否有价值、是否理解选择成本、损失后是否知道怎样恢复。

进度只保留在当前运行中。退出 Play 或重新开始会清空状态；磁盘存档、春季、农业与双语完善属于后续阶段。

开发侧自动逻辑回归已通过；手感、自由建造体验和 30–45 分钟节奏由用户试玩确认，M1-07 当前待用户验收。
