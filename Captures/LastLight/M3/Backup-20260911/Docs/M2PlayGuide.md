# 《留灯地球》M2 试玩说明

## 入口

Unity 菜单：**Tools → LastLight → M2 → Open Prototype**，进入 Play。场景：`Assets/LastLight/Scenes/M2Chapter.unity`。

Windows：`Builds/LastLight/M2/LastLight.exe`。整个 M2 文件夹需要一起保留；首次启动选择“新游戏”，以后可以“继续游戏”或选择手动存档。无需联网。

Windows 存档位于 `%USERPROFILE%/AppData/LocalLow/DefaultCompany/Chongfandiq/M2Saves/`。`manual-1`～`manual-3` 是手动槽，`auto` 是自动档；每槽旁的 `.bak` 为最近有效备份。损坏文件会保留并显示恢复结果，不会静默新开游戏。

## 操作与设置

- WASD 移动，Shift 冲刺，鼠标左键维修锤，E 交互，F 进食。
- B 建造，R 旋转，方向键平移建造镜头，滚轮缩放，Tab 背包，J 日志，Esc 关闭界面／暂停。
- 设置可切换简中／英文、字号、音量、画质及主要动作按键。Esc 保留为关闭和取消；建造镜头方向键与滚轮为固定操作。
- 阅读、菜单和建造规划暂停世界。按钮点击不穿透为攻击。

## 第一章与农业

1. 阅读暖灯终端，拾取物资并存入公共仓储，修复应急暖炉。
2. 建造至少四格、带门围合的小屋，放床、仓储和工作台。生活设施需要地板，种植箱可放室外。
3. 前往旧工坊，沿外围避开枝角兽，阅读撤离记录，取得梁的启动件并返回。
4. 唤醒梁、领取四份零件，回应岑的求援。援助、交换和拒绝都能继续；交换需另备访客床和两份口粮，也可延期一次或明确撤回。
5. 阅读防御说明，准备木障或加固门闩，确认开始首次袭击。失败损失有上限，维修后可以恢复。
6. 在终端阅读后果，处理损坏和未履行承诺。备好木材 ×8、零件 ×3，安排梁修桥；岗位必须开启且通路可达，完工时一次扣料。
7. 修桥完成进入春季。沿西侧桥前往温室，领取三种永久种源，阅读生物维护记录。
8. 建造种植箱，种口粮薯、纤维草或油籽。首次口粮播种免费；后续播种消耗对应普通资源 ×1，成熟产出 ×6。满仓时作物留在箱内，成熟后不腐烂。

春季正常成长时间为口粮薯 150 秒、纤维草 180 秒、油籽 210 秒。冬末露天效率 25%，保护升级提高至 80%；春季为 100%。保护罩需废金属 ×3、纤维 ×2。损坏暂停生长；移动保留作物，先采收才可拆除。安全拾荒与手工制作始终保留。

春季每游戏日为 15 分钟。食物相关警报返家后给予 45 秒准备时间；仓储位置会改变袭击目标位置。安全睡眠统一结算时间、农业、饱食和燃料，已知威胁不能跳过。

## 存档与恢复

- 三个手动槽及一个自动档，每槽保留最近有效备份。手动覆盖需要确认。
- Windows 默认位置为 Unity 的 `Application.persistentDataPath/M2Saves`（实际完整路径见验证记录）。
- 自动保存发生在关键操作、场景往返、睡眠及桥梁完工后。主菜单冷启动不会覆盖进度。
- 主文件损坏时尝试备份并提示；均无效时保留文件和当前可用进度，不悄悄开始新游戏。
- 存档包含库存、建筑损坏与床位、作物、梁岗位、时间、威胁与敌人攻击状态、选择、承诺和已读日志。
- 进行中的普通维修在读档时取消，重新开始即可；未完成不扣材料。桥梁工程进度保存。

## 样板边界

本版为完整首章和温室农业样板，持续停留春季。芽、渡、第二章完整剧情、夏秋冬完整循环和终局内容仍属于后续阶段。

开发侧验证逻辑，不自动判断手感、难度感受或一小时节奏。用户试玩反馈后继续修正。
