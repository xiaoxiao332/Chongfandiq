# SnowVillage 美术规格

用户已确认当前效果，后续扩展以本版为视觉基线。

本文记录已确认的 SnowVillage；《留灯地球》的四季、机器与家园目标见 [主策划](../Design/GameDesign.md)。未来目标不替代本文的现有参数，也不代表已制作完成。

## 1. 风格

参考用户的俯视雪地截图，采用低多边形、低饱和冷蓝环境和简化轮廓。雪地占主体，深色木质建筑和电线杆提供结构，人物以橙红围巾与帽顶点缀形成识别点。

保持空间留白和小人物比例，以主镜头下的轮廓识别为优先，近景保留冬装细节。原图无法确定的人物细节和动作由本项目补全，不要求像素级还原，不包含水印与播放按钮。

视觉基线：[最终场景](../../Captures/SnowVillage/FinalScene.png)、[人物近景](../../Captures/SnowVillage/FinalCharacter.png)。

| 项目 | 当前基线 |

人物起点在中央附近，木棚在右侧，木屋局部进入顶部边缘，井在左上，围栏斜过左下前景，电线杆在右前景，电线斜穿画面。远处枯树投影补充空间层次。

当前木棚布景缩放 1.15，右前景电线杆纵向缩放 1.5，用于匹配此镜头，并非所有未来关卡的统一尺寸。

## 3. 资产要求

人物保留帽子、橙红围巾、厚外套、拉链、口袋、手套、裤腿、靴筒与鞋底；轮廓厚实，面部简洁。保留低分段平面结构，不混入写实皮肤、毛发或复杂纹理风格。

动作范围为 Idle 和 Walk。待机轻微呼吸，行走有抬脚、屈膝、摆臂和重心变化。控制器负责位移，动画原地播放；后续调整应保持脚掌接地和速度匹配。这些是制作目标，最终全面动作测试未完成。

| 资产 | 视觉特征 |
| --- | --- |
| Woodshed | 深色分板、简单门、带积雪屋顶 |
| Cabin | 横木板、窗格、窗台雪、斜屋顶和烟囱 |
| CoveredWell | 多边形井体、双支架、带雪双坡顶 |
| FenceSection | 细横栏、立柱与窄积雪顶面 |
| UtilityPole | 细长杆、横担、绝缘子与细电线 |
| BareTree | 稀疏分枝，以轮廓和长投影辅助画面 |
| 雪地 | 连续起伏和缓坡、浅蓝亮面、蓝灰暗面 |

以纯色粗糙材质为主，当前没有专门绘制的人物/建筑贴图流程。雪面来自几何起伏，部分法线水平分量被放大以增强风格化明暗，不等同于物理坡度。

## 4. 色彩与灯光

以下是构建工具 `Colors` 字典中的 RGB 0–1 输入值，不是最终屏幕取色。

| 材质键 | RGB | 用途 |
| --- | --- | --- |
| Snow | `(0.67,0.80,0.96)` | 雪地及积雪 |
| OldTimber | `(0.27,0.34,0.41)` | 木材 |
| DarkWood | `(0.18,0.24,0.31)` | 深色结构 |
| TimberEdges | `(0.36,0.44,0.51)` | 边框 |
| Parka | `(0.29,0.38,0.44)` | 外套 |
| RustScarf | `(0.85,0.28,0.12)` | 围巾与点缀 |
| Face | `(0.72,0.49,0.37)` | 面部 |
| BootLeather | `(0.15,0.20,0.25)` | 靴子和手套 |

- 普通材质 URP/Lit：Smoothness=0.02、Metallic=0。
- 方向光：欧拉角 `(27,-125,0)`，颜色 `(1,0.94,0.86)`，强度 1.05，软阴影，阴影强度 0.78。
- 环境光 Trilight：天空 `(0.62,0.75,0.94)`，水平 `(0.40,0.55,0.73)`，地面 `(0.31,0.43,0.62)`；关闭雾。
- 后期：曝光 +0.6、饱和度 -2、对比度 +5、Neutral Tonemapping；HDR 与 SMAA。
- SnowPipeline：阴影距离 110，主光阴影贴图 4096；保持向左下区域延伸的长影。

## 5. 雪地反馈与扩展

- 旧脚印当前 54 枚，沿弯曲路线纵向间隔 0.58，左右交替。
- 动态脚印为贴地浅网格，通过暗心与亮边模拟凹陷，不实际挖掉地形；容量 256，覆盖最旧脚印。
- 每次有效落脚产生 5 粒雪粉；雪粉上限 180，寿命 0.6 秒。
- 飘雪上限 450，发射率 24/秒，寿命 14 秒，尺寸 0.025–0.075；保持稀疏，不遮挡主体。

新资产先对齐主镜头比例、明暗与色彩，再加局部细节；橙红色主要用于人物识别。大幅改色或新主题另存场景，保留已确认基线。导出和覆盖规则见 [技术流程](../Technical/ModelPipeline.md)。


## LastLight M2 样板扩展

SnowVillage 场景、材质和模型保持保护基线。M2 在自己的生成目录中复用冷蓝冬末和暖色功能提示；春季使用低饱和绿灰地面和植物变化。桥梁具有修复前后外观，作物显示三段生长阶段，保护架可见。M2 新模型及 Blender 源文件独立存放，不修改 SnowVillage 资产。
