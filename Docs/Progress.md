# 项目进度

## 文档职责

[《留灯地球》主策划](Design/GameDesign.md)定义产品目标、玩法规则、内容范围和体验要求，是“做什么”的唯一来源。本文件将策划拆成可以依次实现和验收的阶段任务，是“现在做什么”的唯一来源。

任务必须引用主策划章节编号：

- `GD-01～03`：产品、核心循环、首小时与区域。
- `GD-04～07`：生存资源、建造伙伴、战斗威胁、四季时间。
- `GD-08～10`：世界人物、事件选择、工程结局。
- `GD-11`：数据、界面、输入和体验契约。

状态只使用：待开始、进行中、开发侧已完成、待用户验收、已完成、阻塞。开发侧逻辑验证与用户手感验收分别记录，不互相替代。

## 执行规则

1. 用户要求“按进度继续”时，只执行当前任务；完成其开发侧条件后更新状态和证据。
2. 新需求先定位主策划章节。若改变设计，先更新主策划，再拆分或调整本文件任务。
3. 实现细节放入 [技术架构](Technical/LastLightArchitecture.md)，不在本文件复制代码结构。
4. 开发侧完成编译、Console、规则和必要 PlayMode 回归；用户负责主观手感与完整流程节奏。
5. 一个阶段通过后才进入下一阶段。发现体验问题时先修正已有循环，不提前扩展内容。
6. SnowVillage 是受保护视觉基线，不纳入 LastLight 阶段任务的覆盖范围。
